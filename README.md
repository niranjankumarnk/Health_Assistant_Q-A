# 🚀 OCI Generative AI Chatbot  
**An AI-powered chatbot leveraging Oracle Cloud Infrastructure (OCI) Generative AI, LangChain, ChromaDB, and OpenSearch for efficient contextual question-answering.**  

## 📌 Features  
✅ **LLM-powered chatbot** using **OCI Generative AI** for natural language understanding.  
✅ **Retrieval-Augmented Generation (RAG)** with **ChromaDB & OpenSearch** for document search.  
✅ **Cohere embeddings** for vector-based semantic search and retrieval.  
✅ **Conversational Retrieval Chain (CRC)** with memory tracking for enhanced user interactions.  
✅ **Deployed using Streamlit** for an interactive web-based user experience.  

## 🏗️ Tech Stack  
- **Programming Language:** Python  
- **Frameworks & Libraries:** LangChain, ChromaDB, Streamlit  
- **Cloud Services:** Oracle Cloud Infrastructure (OCI), OCI GenAI  
- **LLMs & Embeddings:** Cohere, OpenSearch  
- **Storage:** Vector Databases (ChromaDB, OpenSearch)  

## ⚙️ Installation & Setup  
### 1️ Clone the repository  
```bash
git clone https://github.com/your-username/oci-genai-chatbot.git  
cd oci-genai-chatbot
```
### 2 Install dependencies
```bash
pip install -r requirements.txt
```

###  Set up Oracle Cloud Credentials
Update compartment_id and service_endpoint in config.py

### Run the chatbot
```
streamlit run app.py
```
